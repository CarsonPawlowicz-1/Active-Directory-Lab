<h1>Active Directory Lab </h1>



<h2>Description</h2>
Project consists of a virtualized Active Directory environment using VirtualBox to simulate an enterprise IT network. Automated bulk user account creation with PowerShell and practiced daily Tier 1 Help Desk support workflows.
<br />


<h2>Languages and Utilities Used</h2>

- <b>PowerShell</b> 
- <b>Oracle Virtual Box </b>

<h2>Environments Used </h2>

- <b>Windows 10</b> 
- <b>Windows Server 2019 </b>
